# 100 Drone Swarm Simulation

A decentralized coordination system enabling 100 autonomous drones to perform complex tasks through local interactions, avoiding centralized control bottlenecks.

## Project Overview
This project simulates coordinated behavior among 100 autonomous drones in a shared 3D environment. Key focus areas include:
- **Flocking Algorithms:** Separation, Alignment, and Cohesion (Reynolds-style).
- **Decentralized Coordination:** Emergent behavior without central supervision.
- **Optimization:** Use of spatial partitioning (Octree/Grid) and parallel processing to handle large agent counts.

## Implementation Phases
1. **Phase 1 (2D):** Foundation of algorithms and environment in a 2D plane.
2. **Phase 2 (3D):** Graduation to a full 3D simulation with specialized visualization.
